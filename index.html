LOGIC FOUNDRY

Wire up logic gates so the outputs match the specification — for every combination of inputs. The test is deterministic: same circuit, same result. All the skill is in the design.

  • Signals are light. A trace carrying a 1 glows copper; a 0 stays dark. Click an input pin to flip it and watch the board settle.
  • Traces follow your drag. They connect only along the path you draw, so two signals can run side by side without shorting. Cross a perpendicular trace and it bridges automatically.
  • Gates take inputs on the flat sides and drive the output arrow. Rotate with R.
  • RGB LEDs mix additively — Red + Green = yellow, all three = white. Solve each channel, then route it in.
